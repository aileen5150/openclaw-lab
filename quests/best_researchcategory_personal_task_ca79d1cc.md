**Objective:** Deliver a comprehensive competitive intelligence report on the AI coding assistant market segment.

### Primary Research Targets

| Company | Product | Key Differentiators |
|---------|---------|---------------------|
| Microsoft/GitHub | Copilot | Largest codebase training, VS Code dominance, enterprise-first |
| Anthropic | Claude Code | Constitutional AI approach, long context, refusal calibration |
| Cursor | - | VS Code fork, MCP integration, team features |
| Amazon | CodeWhisperer | AWS ecosystem, security scanning, free tier |
| Google | Gemini Code | Gemini integration, multimodal, Android Studio plugin |

### Specific Data Points Required

1. **Market Metrics:** Total addressable market size (current estimate + CAGR), number of active developers using AI assistants, enterprise vs indie breakdown
2. **Revenue Intelligence:** Subscription pricing tiers, estimated ARR for each player, enterprise contract values
3. **Technical Capabilities:** Context window limits, language model versions powering each, latency benchmarks, offline capabilities
4. **Ecosystem Lock-in:** IDE integrations, API access, team collaboration features, self-hosted deployment options
5. **Market Positioning:** Target customer segments, vertical focus (startups vs enterprise), geographic penetration

### Deliverable Format

- Executive summary (200 words)
- Market size analysis with citations
- Detailed competitive matrix
- Win/loss analysis from public sources
- Strategic implications and market gaps

This research will inform go-to-market strategy for a potential entrant in the AI developer tools space.
